# feat(fedimint): real BLS12-381 e-cash blinding + Chaum-Pedersen DLEQ

**PR #323** | CLOSED | Author: botshelomokoka | Created: 2026-08-30 | Merged: 2026-08-30

Branch: `feat/fedimint-dleq-bls` → `main`

## Summary

Implements the remaining `PROTO-001` sub-item ("Fedimint real crypto") by adding real BLS12-381 e-cash blinding and Chaum-Pedersen DLEQ verification, gated behind a new `fedimint-crypto` feature. Without the feature, the module is not compiled and the opaque Fedimint boundary in `fedimint.rs` still returns `ProtocolUnsupported` (fail closed).

## Changes

- **`src/protocol/nexus/fedimint_crypto.rs`** (new, `#[cfg(feature = "fedimint-crypto")]`):
  - `FedimintG1Point` / `FedimintScalar` typed wrappers (compressed G1, little-endian `Fr`) with fail-closed decode (rejects off-curve/out-of-subgroup points, identity, and out-of-range scalars).
  - `blind_message` / `unblind_signature` group-arithmetic helpers.
  - `FedimintDleqProof` generation + `verify()` — Chaum-Pedersen proof that `A = x·B` and `X = x·G` share the same secret, with an RFC 6979-style deterministic nonce to prevent nonce reuse.
- **`Cargo.toml`**: `fedimint-crypto = ["dep:bls12_381"]` (reuses the existing `bls12_381` dependency already introduced for `groth16`).
- **`src/protocol/nexus/mod.rs`**: `pub mod fedimint_crypto;` (feature-gated).
- **`AGENTS.md`**: added `fedimint-crypto` to the feature-gated value-bearing crypto list.
- **`DEBT_INVENTORY.md`**: `PROTO-001` marked 7/7 crypto sub-items resolved; full threshold mint remains provider-gated.
- **`CHANGELOG.md`**: added the feature.

## Scope boundary

This closes the **crypto layer** of the Fedimint debt. The full threshold mint (guardian partial-signature aggregation, network/transport, and live federation integration) remains provider-gated and is not claimed here — consistent with the SDK's fail-closed, no-TEE-bypass ethos.
