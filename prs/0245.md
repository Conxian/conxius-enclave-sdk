# feat(enclave): add provider-neutral trust and replay contracts

**PR #245** | CLOSED | Author: charliecreates[bot] | Created: 2026-07-22 | Merged: 2026-07-22

Branch: `feat/1543-trust-replay-contracts` → `main`

## Summary

- Add typed provider-neutral collateral metadata and digest-only authentication bindings with strict schema, verifier, freshness, expiry, root-set, and revocation validation.
- Add canonical secret-free replay bindings covering provider, proof subject/mechanism, nonce, operation, purpose, policy, key identity, and evidence digest.
- Refactor replay test fixtures to use deterministic test-only value construction without hard-coded nonce material.
- Retain consumed replay binding identities as process-lifetime tombstones in the explicitly non-production in-memory adapter, so reservation expiry cannot be used to extend or reuse a consumed digest.
- Restore deprecated `AttestationPolicy::with_trusted_roots(Vec<String>)` compatibility. Normal library builds reject arbitrary roots and keep provider verification unavailable; crate unit tests retain fixture-only containment.
- Add exact compatibility, replay-expiry, rollback, atomicity, debug, serialization, and production-containment coverage.

## Fail-closed scope

- `AttestationPolicy::production()` and provider verifier status remain unavailable.
- The deprecated string-root compatibility method never installs arbitrary production roots and returns an unsupported error in normal library builds.
- No real provider roots, network refresh, provider authenticator, collateral authority, distributed backend, replay owner, or promotion authority is added.
- `NonProductionInMemoryReplayStore` remains process-local, test/development-only, and is not wired into signing, settlement, or provider paths. Production retention/storage policy remains an architecture decision.
- Existing `ReplayGuard` remains process-local and is not replaced or marketed as durable.
- Capability evidence is intentionally unchanged; this PR records contracts/tests, not production support or release acceptance.
