## Summary

- Add one shared fail-closed containment gate returning a secret-safe typed `ConclaveError::Unsupported` result.
- Invoke the gate in Bisq, Boltz, Changelly, NTT, Wormhole, and x402 before request-body construction and before HTTP dispatch.
- Preserve typed settlement authorization validation/provider-boundary behavior and custom/test rails.
- Update focused production-readiness/evidence wording to distinguish typed authorization containment from adapter dispatch support.

## Why this is fail-closed

The built-in adapters currently use private, unversioned request shapes and do not have verified compatible gateway routes for the existing settlement endpoints. Each adapter now rejects before serializing typed authorization or device evidence and before `reqwest::Client::post`. The fixed error contains no request payload, attestation contents, signature, or URL.
