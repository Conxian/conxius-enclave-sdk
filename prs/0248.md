# feat(enclave): add offline AWS Nitro attestation boundary

**PR #248** | CLOSED | Author: charliecreates[bot] | Created: 2026-07-22 | Merged: 2026-07-22

Branch: `charlie/con-1545-nitro-offline-boundary` → `main`

## Summary

This is an additive, native-only offline structural slice for the AWS Nitro attestation and KMS secret-release boundary. It adds:

- Bounded tagged/untagged `COSE_Sign1` and Nitro CBOR parsing.
- ES384/P-384 leaf-signature verification with an injected certificate-trust boundary.
- Exact PCR, freshness, nonce, attested-recipient-key, and release-binding policy checks.
- A typed KMS `Recipient` / `CiphertextForRecipient` contract without a live AWS transport.

## Security hardening

- Composed verification with a typestate-style receipt: authenticity, local policy, injected trust, and binding checks are sequenced before an offline receipt can be produced.
- Nonzero operation, KMS-key, policy, and replay digests; structural PCR indexes `0..=31`; all-zero/debug PCR rejection.
- AWS-sized `CiphertextForRecipient` bound of `6,144` bytes and RSA SPKI validation.
- Non-recursive CBOR pre-scan before materialization, including a 10,000-depth regression test.
- Plaintext and plaintext-plus-ciphertext KMS response rejection.

## Explicit exclusions and blockers

This PR does **not** provide:

- An authenticated AWS root, collateral, certificate-revocation, or production trust path; the certificate verifier is an injected boundary only.
- Distributed replay consumption (`#240`).
- NSM, vsock, live KMS, or AWS-account deployment evidence.
- EIF/PCR provenance or CloudTrail/runtime evidence.
- Independent production qualification.
- Value-bearing authorization or a production signing/secret-release path.

## Production invariants

- `AttestationPolicy::production().provider_verifier_status()` remains `ProviderVerifierStatus::Unavailable`.
- AWS Nitro capability evidence remains partial/offline structural evidence: integration is `no`, independent review is not evidenced, and production support is unsupported.
- No offline fixture, parser result, or receipt promotes Nitro into production or value-bearing rails.
