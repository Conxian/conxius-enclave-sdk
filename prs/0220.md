## Summary

- Carries typed value-bearing settlement authorization from canonical intent through operation binding, digest, algorithm, operation-key identity, verified signature, attestation/provenance, policy identity, and manager-issued replay authorization.
- Makes typed Opportunity preflight validation-only in every build so valid non-test requests reach provider signing and verified dispatch, while the legacy raw-signature settlement shim remains rejected outside tests.
- Enforces settlement-specific purpose, canonical domain, and canonical intent-digest context at the rail authorization boundary, with negative coverage for wrong purpose/domain/context.
- Sends the verified authorization envelope through Opportunity plus the `bisq`, `boltz`, `changelly`, `ntt`, `wormhole`, and `x402` adapters.
- Preserves the signer-identity evidence and fail-closed provider boundary from PR #216, building on the containment baseline in PR #205 and the typed protocol boundary merged in PR #219.

## Threat boundary

- Raw-signature settlement remains rejected outside isolated test fixtures; production value-bearing callers do not route through `EnclaveManager::sign`.
- The default provider remains unavailable for verified value-bearing settlement, software drivers remain test/development-only, and WASM development constructors remain explicitly feature-gated.
- Replay protection is process-local containment and is consumed before downstream adapter execution; this PR documents and tests that single-use behavior.
- No distributed replay coordination, real hardware/provider verifier, vendor roots/collateral, provider-backed runtime evidence, live adapter compatibility, independent review, or exact release artifacts are added.
