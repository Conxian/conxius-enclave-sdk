# P0: Implement FROST DKG (part1/part2/part3) wrappers

**Issue #265** | CLOSED | Created: 2026-08-03 | Updated: 2026-08-03

## Summary

ZF FROST v3.0.0 includes a complete Pedersen DKG implementation in `frost-core/src/keys/dkg.rs`. We need to wrap `dkg::part1()`, `dkg::part2()`, and `dkg::part3()` in `frost_crypto.rs`.

## API to wrap

```rust
// Part 1: Generate secret polynomial + public commitment
fn dkg_part1(id_bytes, max_signers, min_signers) -> (secret_pkg_bytes, package_bytes)

// Part 2: Verify round-1 packages, send shares to peers
fn dkg_part2(secret_pkg_bytes, round1_packages_map) -> (secret_pkg_bytes, round2_packages_map)

// Part 3: Verify received shares, compute final KeyPackage
fn dkg_part3(secret_pkg_bytes, round1_packages_map, round2_packages_map) -> (key_package_bytes, pubkey_package_bytes)
```
