# [P0] Operationalize attestation roots, collateral, revocation, and distributed replay

**Issue #240** | OPEN | Created: 2026-07-22 | Updated: 2026-07-26

Parent: [SDK umbrella #195](https://github.com/Conxian/conxius-enclave-sdk/issues/195)

Linear umbrella: [CON-1512](https://linear.app/conxian-labs/issue/CON-1512/p0-enforce-hardware-backed-signing-and-mandatory-attestation-for-value)

This focused tracker does not close #195 or CON-1512 by itself. It is the shared provider-neutral trust and replay gate for the Android and Nitro implementation trackers.

## Goal

Shared provider-neutral trust operations for Android, Nitro, future TPM/FIDO/TEE providers, and value-bearing authorization.

## Acceptance checklist

- [ ] Manage versioned authenticated root/collateral bundles as release inputs.
- [ ] Enforce deterministic fail-closed provider revocation, expiry, TCB/measurement, and freshness policy.
- [ ] Implement atomic distributed `consume_once` replay/idempotency durable across replicas, restarts, and regions; fail closed on uncertainty.
- [ ] Bind replay keys to provider, proof subject/mechanism, nonce, operation, purpose, policy digest, key identity, and evidence digest without storing secrets.
- [ ] Test collateral refresh, outage, rollback, rotation, audit, and recovery.
- [ ] Link exact artifact/SBOM/provenance/independent review evidence before provider promotion.
- [ ] Prove no software fixture or stale collateral promotes a production capability.
